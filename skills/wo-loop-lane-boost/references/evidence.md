# Evidence contract

Report five fields:

1. Action — what ran.
2. Result — measurable outcome.
3. Evidence — command output, path, durable id, timestamp, or commit SHA.
4. Risk — what remains uncertain or blocked.
5. Next action — the smallest next step.

A close without evidence is a claim, not completion. Preserve the authoritative work-order id and do not create a duplicate id on retry.
