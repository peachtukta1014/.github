- `code` — ปั้นแป้ง
- `files` — ข้าวของ
- `gaming` — เกมมิ่ง
- `hokkien` — เกี๊ยว
- `jii` — จี้
- `research` — ข้าวเรียม
- `scheduled` — เวลา
- `seafood` — กุ้งทอง
- `tea` — ชาเย็น
- `webhook` — หมึกสาย

Resolve the active session with `lane-id`; never infer a lane from a user nickname.
